# 第2轮：模块化固件与四组合

- 日期：2026-11-07
- 对应步骤：第2步已完成；第3/4步软件已实现、待实测
- 修改前基线：`f14ac01`；最初回退基线：`95f20c1`

## 做了什么

1. 新固件拆为板级适配、IIM-42352/IIM-42652驱动及共享采集/时钟/GNSS/协议/无线模块。
2. 主入口只调用应用begin/tick；寄存器使用命名常量；新代码统一格式。
3. 建立4个正式环境和4个USB测试环境；EoRa设置4MB Flash/Quad PSRAM；明确节点编号。
4. LEDC以XTAL为源输出32000Hz；PCNT在输出引脚回读脉冲，处理溢出并用60秒PPS测量频率。
5. 传感器初始化/自检后待机；START_AT确认并去重，到未来UTC启动；STOP发送尾包。
6. 实现28字节头、25组int16 XYZ、CRC16的v3包，正常长度180字节。
7. 使用异步LoRa发送，保留待确认队列、批量确认和补传窗口；错误与恢复状态分别记录。
8. 共用既有GNSS映射，并修正空RMC字段解析和增加NMEA校验。
9. 原src/include/lib和环境保存为独立旧入口，不覆盖原驱动。

## 使用变化

先按四套接线表选择环境；Heltec CLKOUT=GPIO3，EoRa CLKOUT=GPIO36/PPS=GPIO41。
新环境不使用DS3231，IIM-42652陀螺仪关闭。上电等待GNSS/时钟健康及START_AT，不自动正式采集。
OLED状态界面尚未实现，当前通过串口和上位机查看状态。
