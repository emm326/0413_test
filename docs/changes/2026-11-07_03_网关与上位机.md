## 做了什么

1. 新增Tk上位机：网关连接、节点查询、50/100Hz和量程、时长、开始和停止、状态及保存目录。
2. 实现Semtech UDP v2的PUSH/PULL应答、原始LoRa下发和TX_ACK结果显示。
3. 开始命令按节点掩码广播3次并等待节点确认，使用GNSS状态时间估计启动UTC；停止会取消尚未发送的START重试。
4. 实现5秒收发窗口、批量位图确认、重复数据再次确认，匹配固件v3。
5. CSV按运行/节点保存，去重、有限乱序缓存、尾包和缺口统计；收到UTC和估算延迟写入包诊断CSV，定期更新报告。
6. 新增网关配置生成器，从实际原配置合并项目参数，保留射频类型、校准、功率表和TX范围。
7. 完成网关、上位机、排查、回退说明；旧说明标记为legacy，根README指向新入口。
8. 新增21项行为测试，覆盖协议、真实本机UDP、命令、去重排序、配置合并和CSV。

## 如何使用

- 接线/烧录：docs/wiring_and_flash.md。
- 项目根目录运行：python -m host --nodes 1001,1002 --output data/e870。
- 网关原配置导出后，运行python -m host.configure_gateway生成独立项目配置；操作见docs/e870_setup.md。
- 网关UDP上下行1700；初始控制SF6BW125、470.3MHz、私有LoRa、正常IQ。
