# 正式tx固件50Hz采样复测通过

- 更新日期：2026-11-16（Asia/Hong_Kong）
- 对应步骤：阶段4～5，EoRa-S3-400TB + IIM42652 单节点正式采样复测

## 结论

通过。正式 tx 固件在室外 GNSS 健康条件下完成 60 秒、50 Hz 采样，共 2972 个有效样本，无丢样、FIFO 错误或时间戳异常。

## 做了什么

1. 核对代码：`git diff cb99db0 HEAD` 只包含文档变化，`firmware/` 与 `platformio.ini` 没有差异，确认当前 HEAD 的固件就是之前采样成功的代码。
2. 烧录台架环境 `eora_s3_400_iim42652_bench`，启动自检 3 次均报 `vendor_init`。该环境只额外定义 `APP_USB_TEST=1` 和 `APP_REQUIRE_TIME_SYNC=0`，传感器初始化逻辑与正式环境相同。
3. 改烧正式完整固件 `eora_s3_400_iim42652_tx`，启动自检仍为 3 次 `vendor_init`。
4. 执行一次 `SENSOR_RETRY`，传感器恢复，`state=1`；`GPS_DIAG` 为 `fix=1,pps=1,time=1,healthy=1`。
5. 发送 `START_AT <epoch_us> 50 4 7010 60`，完成 60 秒采样。
6. 发送 `STOP`；队列非空，节点保持 `state=4`。

## 文件变化

只改文档：本报告和 `PROJECT_PLAN.md`。固件、驱动、构建配置均未修改。

## 接线、烧录和操作变化

- 接线不变：VCC、GND、SCK47、MOSI48、MISO39、CSB40；INT1 GPIO38；CLKIN GPIO36；GNSS RX=GPIO16、TX=GPIO15、PPS=GPIO41。
- COM8 烧录正式 tx 固件：RAM 54676/327680 字节，Flash 393573/1310720 字节。
- 节点号 1003、±4g、50 Hz 和 LoRa 参数不变。

## 边界

- 未验证 E870 实际收包和 ACK；队列累计 119 个测试包，节点因此保持 `state=4`。
- 外部 32 kHz CLKIN 不可用，采样使用 IIM42652 内部时钟；`clock_hz` 和 `ppm` 字段不参与内部时钟判定。
- 冷启动时传感器自检不稳定，本次需要手动 `SENSOR_RETRY` 才能恢复；该现象仍需持续观察。
