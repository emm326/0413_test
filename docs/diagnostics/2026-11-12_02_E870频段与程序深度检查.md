## 1. 结论

用户指出的 470–510 MHz 标称工作频段有厂家资料支持，也有设备自带驱动代码支持。此前读到的 500–510 MHz 是当前 CN470 配置的下发允许范围，不能由此判断整台硬件只能在 500–510 MHz 发射。

这台网关可以继续推进项目适配。目前没有证据要求更换网关。470.3 MHz 的实际发射功率、射频通路和节点接收仍未测试；不把资料或源码支持写成实机验收通过。

另外，设备自带 HAL 对 SF5/SF6 使用私有同步字 0x12；不能仅凭 `lorawan_public=true` 判定本项目的 SF6 无法收发。

## 2. 频段证据

### 2.1 厂家标称

2026-11-12 从亿佰特 E870-L470LG12-O 产品页读取到：

- 工作频率：470~510 MHz。
- 发射功率：27 dBm（产品标称，并非本轮测量）。
- 半双工、支持二次开发、支持 CN470 地区文件。

官方原始地址：`https://www.ebyte.com/product/2588.html`。

现场下载快照位于 [厂家页文本](../../tmp/e870_deep_check_20261112/ebyte_product.txt) 及 `tmp/e870_deep_check_20261112/ebyte_product.html`。产品页给出整机工作频段，没有在本轮读取的内容中逐点保证 470.3 MHz 的实际发射性能。

### 2.2 设备自带 SX1250 驱动

已通过 COM11/115200 从这台设备导出并逐文件核验源码 SHA256。

[loragw_sx1250.c](../../tmp/e870_deep_check_20261112/device_sources/libloragw/src/loragw_sx1250.c) 第 103–105 行包含：

```c
} else if ((freq_hz > 470E6) && (freq_hz < 510E6)) {
    buff[0] = 0x75;
    buff[1] = 0x81;
```

因此 470.3 MHz 在驱动镜像校准的这个分支范围内。条件使用严格大于/小于，不能说源码已经覆盖精确 470.000 MHz 和 510.000 MHz 端点。该代码同样不能单独证明整机 PA、滤波、功率、频谱和天线性能已验收。

### 2.3 500–510 MHz 限制从哪里来

设备 [lora_pkt_fwd.c](../../tmp/e870_deep_check_20261112/device_sources/packet_forwarder/src/lora_pkt_fwd.c)：

- 第 864–868 行从 JSON 读取 `radio_0.tx_freq_min/max`。
- 第 3844–3847 行在发射入队之前比较数据包频率与该允许范围，越界时返回 `JIT_ERROR_TX_FREQ`。
- 第 1712–1714 行将该错误编码为 UDP 的 `TX_FREQ` 回应。

当前原厂配置为：

```json
"tx_enable": true,
"tx_freq_min": 500000000,
"tx_freq_max": 510000000
```

因此，保持当前配置时，470.3 MHz 会被应用程序拒绝。这是由设备源码和实际文件作出的推断，本轮未通过发送测试触发这个回应。

Semtech 官方 V2.1.0 `global_conf.json.sx1250.CN490` 参考文件同样使用 500–510 MHz TX 范围；已下载对照，存于 `tmp/e870_deep_check_20261112/upstream_cn490.json`。这说明其与地区配置范例一致，但不能仅凭相同数值断言本机文件具体来自哪次上游提交。

现有项目生成器仍基于原配置的允许范围判定，因此返回不支持；这一结果描述的是当前文件是否允许下发，不是整台硬件能力鉴定。本轮没有修改生成器或伪造新的 factory 配置。
