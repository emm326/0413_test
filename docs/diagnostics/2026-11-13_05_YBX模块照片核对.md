## 2. 与官方芯片手册及代码的对应

| 图中标注 | 现有1003配置 | 核对结论 |
|---|---|---|
| VCC | 现有3.3V供电 | 模块额定输入和内部供电仍未确认，照片不等于供电规格 |
| GND | 主控GND | 信号参考地约定一致 |
| SCK | GPIO47 | Board.h一致 |
| MOSI | GPIO48 | Board.h一致 |
| MISO | GPIO39 | Board.h一致 |
| CSB | GPIO40 | 与SPI片选信号名称对应 |
| INT1 | GPIO38输入 | 与芯片INT1功能约定对应 |
| INT2 | GPIO36输出32000Hz，模块端计划用作CLKIN输入 | 芯片封装脚9复用INT2/FSYNC/CLKIN，丝印INT2不否定CLKIN能力；板级连通路径仍待原理图或测量 |

官方TDK DS-000440手册还说明：INTF_CONFIG4的SPI_AP_4WIRE默认1，即芯片默认四线SPI；INTF_CONFIG5的PIN9_FUNCTION=10选择CLKIN。现有IimBase.cpp已有PIN9_FUNCTION和RTC_MODE配置。不能仅凭WHO读取失败就认定芯片必须先用I2C切换SPI，或断言需要改焊某个跳线。

这里核对的是芯片功能和现有程序约定；尚未取得YBX模块板级原理图，不能把芯片规格直接替代模块VCC要求。

## 3. 尚不能从照片确定的内容

- 外围器件丝印无法可靠读清，不能确认哪一颗为稳压、电平转换、阻容阵列或其他器件。
- 未见背面资料，不能确认焊桥、跳线和各排针到芯片的实际路径；正面没有可明确识别的接口选择说明。
- 不能确定VCC额定电压、VDD/VDDIO实际电压和SPI输出高电平是否与主控输入阈值匹配。
- 图片不能证明当前MISO、CS/SCK或CLKIN/INT1波形，也不能判断模块是否损坏。

## 6. 下一步

获取这款模块的购买链接或商家配套说明、原理图，重点确认额定VCC、内部VDD/VDDIO以及SPI/CLKIN排针电路；必要时补背面照片。资料未确认前保持当前供电与接线，不根据元件外观改变电压或旁路电路。

再依据板级电路决定测量位置，测模块端供电、CS/SCK/MISO及CLKIN/INT1波形，或使用已知正常模块对照。只有稳定读到0x6F且DRDY/FIFO自检通过后，才继续1003单节点50Hz和ACK/STOP验收。
