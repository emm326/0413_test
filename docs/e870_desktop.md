# E870 桌面工作台操作说明

本版提供网关配置、采集控制和诊断三个页面。先验证真实网关，节点采集另行验收；没有节点/GNSS/PPS/时钟就绪时，不能开始正式采集。

## 打开软件

双击项目根目录的 `启动E870上位机.cmd`。运行环境在 `.venv/`；正常启动不会自动联网安装，不需要手动打开命令行。密码只保存在本次会话，关闭后不保存。

当前项目的固定依赖在 `requirements-desktop.txt`。如果迁移到另一台电脑，需要维护人员先建立 Python 3.12 独立环境并安装此文件，不能只复制启动入口。

## 网关配置

1. 给网关供电、连接 LoRa 天线，将 WAN 接电脑；首次设置再接 USB2 数据线。
2. 选择 USB2串口，刷新并选择实际 COM 口。账号为设备交付账号；手册出厂为 root/root，修改过时使用实际密码。
3. 点击“连接并读取”，检查设备身份、当前服务和地址，再“备份当前配置”。
4. 电脑有线地址使用 `192.168.1.22`，网关目标 `192.168.1.10/24`。软件不会替你改电脑网卡或关闭防火墙。
5. 点击“读取并预览差异”，审阅网口和项目无线/转发改动。
6. 点击“应用网口设置”。程序先备份，设置、读回、检查 IPv4；失败会恢复。网口必须通过 USB2 修改。
7. 再次“读取并预览差异”，然后“应用无线/转发设置”。应用网口后必须重新预览，避免使用过期快照。
8. 项目配置写到独立的 `desktop_*.json`，切换配置链接后重启并检查服务，不覆盖原厂 CN470 文件。

项目设备档明确采用 E870-L470LG12-O 的 470–510 MHz 配置范围，保留原厂校准、功率表和原始备份。配置允许下发不代表射频实测通过。普通配置生成路径继续保留原限制，需要显式选择设备档才会适配。

后续可在同一界面改选 SSH网线，地址 `192.168.1.10`。首次记录 SSH 主机指纹，后续指纹变化会拒绝连接；无需再占用串口。设备更换或 SSH 密钥变化需维护人员核验身份。

## 恢复配置

先结束运行，断开电脑接收服务，再通过 USB2 建立管理连接。点击“恢复备份”，选择包含 `manifest.json` 的备份目录。

程序会核验设备身份和备份 SHA256，再恢复所选网口文件、配置内容及软链接，并读回确认。原始 DHCP 备份恢复后，电脑直连可能不再有 IPv4 连接，USB2 仍可管理。要恢复为可用状态，可再次预览并应用项目设置。

完整备份位于 `gateway/state/backups/`；设备侧另留备份副本。`gateway/state/` 被 Git 忽略，不进入提交。恢复的是网口与网关配置，不是刷写系统或恢复所有系统文件。

## 接收与采集控制

在“采集控制”页点击“启动接收服务”。这只表示电脑 UDP 1700 开始监听，须等到真实网关 PULL 心跳，才能显示“网关心跳正常”。端口占用时会明确提示。

可输入目标节点 1001–1008，也可在表格多选。首次启动默认全部八个节点；接收服务已启动后如选择超出该次接收目标的节点，需断开并重启接收服务。

- “查询节点”：下发状态请求，15 秒后总结；无回复显示“暂未发现节点”。
- “预约开始采集”：本阶段只开放 50 Hz/SF6。检查在线、待机、GNSS/PPS、时钟、网关和时间映射后，下发未来 UTC 开始时间；必须收齐本次运行的成功确认。
- “停止并等待收尾”：仅对当前运行下发，最多三次，等待全部目标节点待机、队列为零；30 秒未收齐会标为“停止未确认”，不会伪造结束。
- 运行中关闭软件：默认停止并等待。超时可以明确选择强制退出，记录未确认状态；强制退出不等于节点停止。

现有 CSV 按运行编号和节点分别保存。固定时长的样本终点过滤、同步精度和无线实机效果仍按项目计划后续验收。

## 网关下发自检

必须同时有管理连接和真实 UDP 网关连接，并确认 LoRa 天线接好。点击“470.3 MHz下发自检”，确认后以 14 dBm 发三次专用测试报文，间隔至少 2 秒。

专用报文不是 START/STOP，不启动采集。每次核对 token 和 TX_ACK；再核对当前测试窗口内的网关实时发送成功计数 txnb，并读取当前启动日志检查错误，观察最多 45 秒。重复状态包只计一次；文字日志缓冲不会代替实时成功计数。只有三次 ACK 全为 NONE、发送计数至少三次且没有发送错误，才标为通过。

“网关自检通过”不等于节点收包成功，也不是功率、频谱或同步精度验收。失败会保留拒绝原因、超时和原始证据，不自动标为成功。

## 日志与排查

“诊断与测试”页可查看 PUSH/PULL/TX_ACK 数量、各命令状态和网关服务日志，导出本地 JSON 检查报告。会话记录在 `gateway/state/last_session.local.json`，不含密码。

- 没有串口：检查 USB2、数据线和驱动，刷新设备；避免其他程序占用。
- 只有接收服务启动：核对网关服务器地址、电脑有线 IP 和 UDP 1700，不要关闭全部防火墙。
- 下发 TX_FREQ：核对设备实际在用配置，不把网关仍使用原厂文件误当成项目配置已部署。
- 下发 ACK 超时：核对网关下行心跳和运行日志；重连后重新自检。
- 设备日期不对：报告以电脑时间记录，设备日志保留原时间；本版不会在后台悄悄校时。
- 当前无节点：开始按钮保持不可用是预期结果，不能用网关自检代替节点验收。
