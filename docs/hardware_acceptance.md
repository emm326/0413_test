# E870 八节点实机验收记录

当前尚未烧录、未连接 E870。软件测试和编译通过不等于实机验收，以下项目完成后逐项填写结果。

## 1. 单节点硬件

1. 按 `wiring_and_flash.md` 接线并烧录对应 USB 测试环境。
2. 记录板型、传感器、`APP_NODE_ID`、提交号、串口和供电。
3. 示波器检查 CLKOUT/CLKIN 为 32000 Hz、50% 占空比。
4. GNSS 锁定后连续至少 60 秒 PPS 计数，目标时钟误差 ±100 ppm。
5. 检查 50 Hz 实际采样率、DRDY/FIFO、量程和静止/翻转方向。

## 2. E870 联调

1. 导出原厂配置，确认 TX 路径和范围实际支持 470.3 MHz。
2. 验证 8 个上行信道同时接收，记录每个节点 RSSI/SNR。
3. 验证 470.3 MHz 下行、TX_ACK、节点 CONFIRM 和单包 8 节点批量 ACK。
4. 区分网关 TX_ACK 与节点 CONFIRM；没有 CONFIRM 不得判定命令成功。
5. 验证 STOP、重复 START、缺确认取消、节点重启、过期 ACK 和运行编号不匹配。

## 4. 8 节点 50 Hz 最终验收

- 连续运行至少 2 小时，每节点应约有 360,000 个样本。
- 补传后每节点样本缺失率不高于 0.1%。
- 99% 样本在采样后 10 秒内到达电脑。
- 各节点发送队列无持续增长。
- 8 个节点 CSV 独立，时间戳单调，无跨节点污染。
- 保存 `capture_report.json` 中每节点和整体的到达率、补传率、最终缺失率、最大延迟及 10 秒内到达比例。
