# 实机验收记录

当前未检测到串口设备，未烧录、未部署网关。以下按方案A/B/C/D分别记录实测。

## 第3步：时钟与传感器

1. 按wiring_and_flash.md接线，先烧录对应usb_test环境。
2. 记录板型、传感器、节点、提交号、供电和CLKIN引出方式。
3. 示波器检查主控CLKOUT和传感器CLKIN：32000Hz、50%占空比。
4. GNSS锁定后连续至少60秒PPS计数，记录clock_hz/ppm，目标±100ppm。
5. 分别启动50/100Hz测试，统计DRDY、实际样本数、丢样和时间间隔。
6. 每种组合记录静止XYZ、翻转重力方向和满量程设置是否正确。

## 第4/5步：无线开始与上位机

1. 烧录对应tx环境，确认上电待机，未收到命令不输出正式数据。
2. 导出网关原配置，用配置生成器检查并实测470.3MHz控制下行。
3. 连接上位机，查询节点；两个健康标志均正常。
4. 开始命令重复3次，核对每个节点确认且只启动一次。
5. 比较指定启动UTC与首样本UTC；首样本按真实DRDY记录。
6. 验证停止、尾包补传、断网恢复、GNSS暂失和节点重启。
7. 检查180字节正常包、短尾包、去重、乱序保存与ACK回收队列。

## 第6/7步：持续与扩容

四组合分别在50/100Hz下运行至少2小时；双节点稳定后逐步增加至8–10节点。
记录：距离、遮挡、天线、频点/SF/带宽、实际采样率、样本缺失、延迟、队列峰值及重传次数。
目标：补传后样本缺失率≤0.1%，99%样本延迟≤10秒。读取packets.csv中的接收UTC和估算延迟；现场校准上位机UTC偏移后统计端到端延迟。
