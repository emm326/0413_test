# 当前项目优化建议

## 优先级 1：完成双节点无线闭环

1. 先用 USB GPS 模式确认两个节点都能稳定输出 51.2 Hz 数据。
2. 烧录 RX、TX1001、TX1002 的同一版本 P2P 固件。
3. 先测试短时间、50 Hz 档，再延长时长。
4. 检查 TX 队列、ACK 超时、FIFO overflow、丢包和 CSV 时间间隔。
5. 对无线 CSV 运行 `tools/sensor_time_error_analysis.py`，使用与 USB 数据相同的误差口径。

## 优先级 2：采集可靠性

- 保持采样与无线发送解耦，采样写入队列，轮询授权后再发送。
- 高采样率下优先增加本地缓存或拆分多个 RX，不降低时间戳质量换取吞吐。
- 每次现场测试记录固件环境、采样率、量程、节点数、运行时长和丢包情况。

## 优先级 3：同步后处理

- 保留原始四列 CSV，不覆盖原始数据。
- 先报告相对偏置、漂移、抖动和未匹配样本，再生成公共 UTC 网格数据。
- 不跨越明显丢样缺口插值。
- 不把结构不同位置的真实振动传播时间误认为时钟误差。
- 同步原理、误差口径和文献依据统一维护在 `docs/sensor-sync-09-principle.md`。

## 当前验收标准

50 Hz 配置对应 IIM 实际约 51.2 Hz，一个采样周期为 `19.53125 ms`。当前阶段要求有效公共区间内的最大匹配时间误差小于一个采样周期，并在报告中给出具体平均值、P95、最大值和漂移 ppm。
